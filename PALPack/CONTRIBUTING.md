# Contributing to PALPack

Thanks for helping improve PALPack! Contributions of every size are welcome: typo fixes, documentation, build photos, bill-of-materials sourcing notes, bug reports and hardware revisions.

## Ways to contribute

- **Report a problem.** Open an issue and include what you built, which board revision or Gerber set you used, photos if you can, and what you expected versus what happened.
- **Improve the docs.** Clearer assembly steps, better photos and sourcing tips help everyone.
- **Propose a hardware change.** Open an issue first to discuss it so we can agree on the direction before you spend time on a redesign.
- **Share your build.** Tag **@valleytechsolutions** and tell us what you made.

## Pull request checklist

1. Fork the repository and create a topic branch.
2. Keep each pull request focused on one change.
3. If you change the board, update everything that depends on it: fabrication files in `hardware/gerbers`, the bill of materials in `hardware/bom`, the specifications in `README.md`, and any affected images.
4. Explain *what* changed and *why* in the pull request description.
